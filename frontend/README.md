# Pupillo Frontend (Next.js + Tailwind CSS)

Questa cartella conterrà l'applicazione frontend sviluppata in Next.js con Tailwind CSS per l'MVP di Pupillo.

## Sviluppo Locale
1. Installa le dipendenze:
   ```bash
   npm install
   ```
2. Avvia il server di sviluppo:
   ```bash
   npm run dev
   ```
